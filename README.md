## ✦ Design Philosophy

I treat engineering and spatial design as complementary disciplines. My work focuses on:
* **System Clarity:** Decoupling complex workflows into lean, maintainable microservices with isolated persistence layers and type-safe contracts.
* **Editorial Performance:** Delivering sub-second initial paints, zero cumulative layout shifts, and 60 FPS momentum scrolling powered by modern static site generation (SSG) and hardware-accelerated motion.
* **Problem-First Execution:** Aligning user research, requirement engineering, and system architecture before writing a single line of production code.

## ✦ Featured Works

### [01. Larasana — D2C Luxury Fashion Platform](https://github.com/SERAVEEM/Larasana-React-nest)
> **🏆 Computer Science Festival Finalist**  
> Direct-to-Customer (D2C) artisan platform connecting 15,000+ Sasak weavers in Lombok directly to global luxury buyers, eliminating predatory middlemen.
* **Architecture:** Decoupled NestJS microservices monorepo communicating via native TCP transport (3–7ms internal latency, 170–225MB RAM).
* **Highlights:** Physical-to-digital QR Story Passports, MySQL ACID transactions guaranteeing 60% artisan royalties, Strategy Pattern Dynamic Shipping Resolver (Biteship, RajaOngkir, EasyPost), Midtrans real-time SSE payment streaming, and Lenis 60 FPS editorial motion in React 19.

### [02. Linear Design — Digital Architecture Platform](https://halolinear.com)
> Digital architecture portfolio engineered for **Linear Studio** to digitalize multi-megabyte architectural PDFs into a spatial narrative web experience.
* **Tech Stack:** Next.js SSG, TypeScript, Cloudflare R2 edge media streaming, custom CAD drawing viewers.
* **Performance:** 99 Google Lighthouse Performance and 100 SEO with sub-second First Contentful Paint.

### [03. Microservice System Jomoro Coffee V2](https://github.com/SERAVEEM/COSC6093001---Jomoro-Coffe-BE-system-)
> Modern, modular backend microservices system engineered to process high-volume coffee orders, inventory catalogs, and automated checkouts.
* **Architecture:** 3 isolated NestJS (v11) services (`auth-service :3001`, `product-service :3002`, `transaction-service :3003`) with dedicated MySQL database schemas mapped via Prisma ORM.
* **Highlights:** Stateless cross-service Passport JWT verification, atomic stock decrement API, Swagger API documentation, and strict programmatic No-Regex payload validations to prevent ReDoS vulnerabilities.

### [04. GPL Yuk! — Environmental NGO Ecosystem](https://www.instagram.com/gplyuk.id/)
> Pro bono digital platform engineered for social and environmental NGO **GPL Yuk!** to streamline volunteer management, event logistics, and donations.
* **Highlights:** React.js & TypeScript volunteer portal, structured Laravel & MySQL backend, automated Midtrans QRIS/VA payment reconciliation, and Cloudflare R2 object storage archiving field photography.

### [05. HYPEN. — Circular C2C Fashion Marketplace](https://github.com/seraveem/hypen-marketplace)
> Mobile marketplace engineered to combat textile waste and accelerate circular fashion adoption in Indonesia (SDGs 12, 13, and 8).
* **Tech Stack:** Flutter (Android & iOS), Node.js & Express v5 REST API, MySQL (15-table relational schema).
* **Highlights:** Contextual per-product WebSocket chat rooms with live price bargaining (*"Tawar Harga"*), automated Midtrans payments, and RajaOngkir shipping calculation.
